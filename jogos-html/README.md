### Ferramentas locais

- [Launcher navegador do Emerald Arena](../ferramentas/Emerald_Arena_Launcher_Navegador.html) — ferramenta experimental: usa ROM **do jogador**, não inclui ROM comercial.
- [Scripts e testes](testes/) — QA e ferramentas de evolução HTML. Alguns testes referenciam nomes de arquivos locais da época e podem exigir ajustes.

Use **Download raw** no GitHub para salvar um `.html` e abrir no navegador. Abrir um arquivo pelo visualizador de downloads do Android pode impedir scripts; prefira um navegador moderno.
