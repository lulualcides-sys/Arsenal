# Pokémon Torre — publicação web

Este diretório contém a versão jogável da **Pokémon Torre V35.79**. O arquivo `index.html` é o jogo completo. Atualizações devem substituir este arquivo sem alterar o endereço do site.

## Salvamento

O progresso é armazenado no navegador (`localStorage`). Para migrar o jogo a partir de um HTML baixado, use **⚙️ > 💾 Baixar backup** no arquivo antigo e **⚙️ > 📥 Importar backup JSON** nesta versão web.

## Observação

Projeto de fã, não oficial. Pokémon e sprites pertencem aos respectivos titulares. Não contém ROM.
