Jogue a batalha de verdade.

Este launcher executa o Emerald Arena original, não uma imitação em HTML. Ele permite preparar sua própria ROM do Pokémon Emerald com o patch BPS oficial e abri-la no navegador usando o emulador mGBA.

Preparar e jogar

ETAPA 01

A ROM é lida no próprio aparelho e não é enviada para nenhum servidor.

ETAPA 02

Baixar patch oficial 0.13.0 ↗

Aguardando arquivo. Selecione a ROM original; para aplicar o patch oficial, selecione também o .bps.
Ao utilizar, você confirma possuir uma cópia do jogo original compatível. Este launcher não contém nem distribui ROMs, Pokémon ou sprites comerciais.
Importante: a integração da nossa Torre de Ginásios ainda depende da compilação do código GBA. Neste launcher você joga o Emerald Arena original, enquanto a torre é preparada.

Emerald Arena rodando no navegador

No menu de um save novo, pressione SELECT em NEW GAME para entrar no modo de teste. Depois pressione L + R na área de campo para começar os combates; use direcional para mover, A para atacar e B + direcional para esquivar.

Como funciona / dicas
  • Jogo real: o patch é aplicado localmente e o núcleo mGBA roda na página.
  • O patch só aceita a versão original compatível de Pokémon Emerald (USA/Europe). Se a ROM for outra, será rejeitada.
  • O emulador requer internet para carregar sua biblioteca. A ROM não sai do seu aparelho.
  • Se a abertura por arquivo no celular bloquear o emulador, abra o HTML no Chrome ou Safari comum em vez de um visualizador de anexos.
  • É possível selecionar uma ROM já preparada sem fornecer o patch.
  • Em telas pequenas, habilite os controles de toque na interface do emulador.
