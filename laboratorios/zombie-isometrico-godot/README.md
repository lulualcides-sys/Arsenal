# Zombie Outbreak — Godot 3D (protótipo de laboratório)

Protótipo autoral de sobrevivência com câmera 3/4 inclinada, zumbis e tiro direcional independente da movimentação.

**Engine:** Godot 4.7.2 (GDScript). **Controles:** WASD mover, Shift correr, mouse mirar e disparar, R recarregar, Enter reiniciar.

Abrir o projeto `project.godot` no Godot e clicar em Play. No GitHub Actions, o runner instala Godot automaticamente, importa o projeto, executa o teste de carregamento e prepara o export Web como artefato CI (quando configurado). Nenhum software é instalado no telefone/PC do usuário pelo workflow.

A inspiração de processo é o [Claude Code Game Studios](https://github.com/Donchitos/Claude-Code-Game-Studios), licença MIT. **Não copiamos nem executamos os scripts de agentes externos** nesta primeira etapa: incorporamos revisão de escopo, brief, smoke-test e isolamento de mudanças.

**Status inicial:** versão técnica / geometria provisória. Não equivale à qualidade visual do vídeo e não foi submetida a playtest humano.
